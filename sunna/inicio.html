Guia · 01

Primeiros passos

Compilar, executar, e entender o que a máquina precisa ter instalado para que a varredura enxergue tudo que pode enxergar.

I · Executar

O aplicativo

A casca egui vive na branch main e é a que compila sem dependência de sistema adicional:

shell 
cargo run -p sunna-egui

A casca Tauri

Vive na branch tauri e usa a WebView do sistema. Exige libwebkit2gtk-4.1-dev instalado antes de compilar.

O motor, sem interface

O exemplo scan roda o núcleo contra o sistema real e imprime o resultado. É o caminho mais curto para ver o que a varredura devolve — e o único jeito de exercitar os coletores sem abrir janela.

shell 
cargo run -p sunna-core --example scan
cargo run -p sunna-core --example scan -- --json
cargo run -p sunna-core --example scan -- --privileged

Ausência tem nome

Coletor que não pôde rodar vira Snapshot::skipped com o motivo escrito. Seção vazia sem explicação é proibida no projeto: ela comunica "não há nada aqui" quando a verdade é "não foi possível olhar".

III · Privilégio

O que fica invisível sem root

Sem privilégio, o nmap não consegue abrir socket raw. A descoberta então degrada para um connect() TCP em 80 e 443 — e um host que filtra essas duas portas simplesmente não aparece na lista.

É exatamente esse buraco que a tabela ARP do kernel preenche, porque responder ARP é obrigatório na rede local. Com --privileged, o pkexec eleva a descoberta e o ARP entra em jogo:

shell 
cargo run -p sunna-core --example scan -- --privileged
Sem privilégioCom privilégio
Descobertaconnect() em 80 e 443 → sweep ARP completo
Host que filtra tudoinvisível → aparece, via ARP
PID de socket alheio"requer root" → o PID real
Nunca deduzido

Quando o PID não está acessível, a interface escreve "requer root". Deduzir o dono de um socket casando nome de processo no ps é proibido: aponta o processo errado sempre que existem homônimos, e um palpite com cara de fato é pior que uma lacuna honesta.
